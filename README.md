# cs3300-project1

## Build and run

From the `project1` directory, start the website:

```powershell
mvn spring-boot:run
```

Open `http://localhost:8080/` for the landing page or
`http://localhost:8080/login.html` for the login page. Press `Ctrl+C` to stop
the server.

To build and test without starting the server:

```powershell
mvn clean test
```
